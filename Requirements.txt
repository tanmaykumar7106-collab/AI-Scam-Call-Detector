*Installation Guide

Follow these steps to set up and run the project smoothly on your system.

1. Clone the Repository

   a. git clone https://github.com/your-username/scam-call-detector.git
   b. cd scam-call-detector

2. Create Virtual Environment (Recommended)

-> Windows

   a. python -m venv venv
   b. venv\Scripts\activate

-> Linux / Mac

   a. python3 -m venv venv
   b. source venv/bin/activate

3. Install Python Dependencies

   a. pip install -r requirements.txt

4. Install System Dependencies (IMPORTANT ⚠️)

-> For Linux (Ubuntu/Debian)

   a. sudo apt-get update
   b. sudo apt-get install portaudio19-dev

-> For Windows (IMPORTANT)

PyAudio installation may fail normally, so use:

   a. pip install pipwin
   b. pipwin install pyaudio

-> For Mac

   a. brew install portaudio
   b. pip install pyaudio

5. Verify Microphone Access

Make sure:

   a. Your microphone is connected
   b. Permissions are enabled

6. Test:

a. python

   i. import speech_recognition as sr
   ii. print(sr.Microphone.list_microphone_names())
